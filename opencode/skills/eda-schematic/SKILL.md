# EDA 原理图解析

帮助用户读懂电路原理图。目标是先得到**精确的连接关系**,再回答任何关于电路的问题。

## 0. 输入类型检测

先确认用户提供了什么。优先顺序:

| 优先级 | 输入 | 解析方式 | 精度 |
|--------|------|----------|------|
| 1 | EasyEDA JSON 源码 (`.json` 含 `head.docType` 或 `element` 数组) | 结构化解析 | 高 |
| 2 | PADS 网表 (`.tel`,文件以 `$PACKAGES`/`$NETS` 开头) | 纯文本解析 | 高 |
| 3 | 其他网表 (`.net` / Spice / Altium / FreePCB) | 纯文本解析 | 高 |
| 4 | 立创EDA专业版工程 (`.epro` / `.eprj`) | 解压/提取 JSON | 高 |
| 5 | 图片 / PDF 截图 | 视觉识别 | 低,仅作辅助 |

若用户只有图片/PDF,**主动提示**导出 JSON 或网表可大幅提升精度,并说明导出路径(见下)。

## 1. 获取源文件

若用户还没有导出文件,引导其按格式操作:

- **EasyEDA 标准版 JSON**:原理图内 `File > EasyEDA File Source > Download` 得到 `.json`(若在网页版项目列表,右键项目 `Download` 得到 zip,解压后是 `.json`)。
- **网表**:原理图内 `File > Export NetList > Spice...`,选择 LTSpice / Protel-Altium 任一格式导出 `.net`。
- **立创EDA 专业版**:项目导出/备份得到 `.epro` 或 `.eprj`,其为内嵌 JSON 的文本或 zip。

## 2. 结构化解析

拿到文件后,按类型解析:

### JSON 源码(推荐)

用脚本或逐段读取,提取三类信息:

1. **元件表**:遍历 `element` 数组,过滤 `head`/`wire`/`text`/`image` 等绘图对象,留下 `prefix`(如 `R`、`C`、`U`)、`name`/`value`(阻值、型号)、`designator`(位号,如 `R1`)。
2. **引脚表**:每个元件的 `pins` 数组,记录引脚 `number` 与 `name`(如 `VCC`、`GND`、`PA0`)。
3. **网络(Net)**:EasyEDA 用**同名网络标签**隐式连接——收集所有 `netlabel`(及 `pin` 关联的 `net` 字段),把相同网络名的引脚归并为一条连接。

若文件较大,先 `grep` 定位 `"prefix"`、`"netlabel"`、`"pins"` 等关键字段的规模,再决定全量读取还是分段解析。

### 网表(纯文本)

直接读取全文。立创EDA 导出 PADS 格式 `.tel` 时,结构为:

```
$PACKAGES
<封装1> ! <封装1> ! <值> ; <位号1> <位号2> ...     ← 元件清单,一行或多行延续
$NETS
'<网络名>' ; <位号>.<引脚> <位号>.<引脚> ...      ← 每个网络一行,引脚相连
$SCHEDULE
$END
```

解析规则:

1. **`$PACKAGES` 段**:每行按 `!` 分三段——前两段重复封装名,第三段 `值 ; 位号`(值可能为 `'{Value}'` 占位,表示未填)。位号可能跨行延续,注意与下一行合并。
2. **`$NETS` 段**:每行 `'网络名' ; 引脚列表`,引脚格式 `位号.引脚号`(如 `U4.7` = U4 的第 7 脚)。连接也可能跨行延续。
3. 网络名 `$1Nxxxxx` 是未命名的自动网络,按用途理解即可。
4. 其余网表格式(Spice/Altium/FreePCB)同理:**先找元件清单段,再找网络清单段**,构建"网络 → 引脚 → 元件"映射表。

### 图片/PDF

用 Read 工具读图;若图复杂,先放大局部逐块读。只用于确认整体布局与大致拓扑,具体引脚连接以导出文件为准。

## 3. 输出结构化摘要

解析后,先向用户输出一份**电路摘要**(中文 Markdown),包含:

1. **元件清单**:位号 | 型号/值 | 数量 | 作用(电阻/电容/电源芯片/MCU/传感器…)
2. **电源树**:所有电源网络(VCC/3V3/5V/GND 等),哪些元件引脚连到哪个电源,是否有 DCDC/LDO、去耦电容
3. **关键信号网络**:MCU 的引脚分配(UART/SPI/I2C/GPIO/PWM/ADC)、时钟、复位、BOOT
4. **接口与外设**:连接器、按键、LED、传感器等外部接口的接线

## 4. 回答问题

在摘要基础上回答用户的问题。常见问题与答题要点:

- **"这块电路怎么工作"**:按信号流向讲——电源输入 → 稳压 → MCU 供电;外设 → MCU 引脚 → 软件控制。
- **"某引脚接在哪/某网络连了谁"**:直接查网络映射表给出确切元件与引脚。
- **"检查有没有设计错误"**:检查电源接反、高低压混接、同名网络误连、上拉/下拉缺失、去耦缺失、方向接错等。
- **"帮我把原理图翻译成代码"**:给出引脚配置、外设初始化所需信息(GPIO 号、复用功能、上拉电阻值)。

## 5. 关键注意事项

- **一切连接关系以数据为准**,不要凭经验脑补某个 IC 的引脚定义;拿不准的封装/引脚归属,用网表或 JSON 中的 `pins` 数据核对。
- 网络标签同名即短接(尤其 `GND`/`VCC`/`3V3` 这类全局网络,可能跨多页)。
- 多页原理图:同名网络跨页相连;解析时合并同名网络。
- 立创EDA 元件值可能放在 `value` 或 `name` 字段,两者都查。
- 若解析过程中字段结构与本说明不符,按文件实际结构自适应,并把关键字段名的发现过程简短记录在回答里。
