# 元器件整理维度指南

先识别类型，再取维度。不同元器件的“关键参数”差异很大，拿 IC 模板套连接器或晶振只会制造噪音。

## 通用规则

1. 先看 Absolute Maximum Ratings 和 Recommended Operating Conditions，再看 Electrical Characteristics。
2. 参数名保留英文，数值带单位、测试条件和页码。
3. 区分保证值（min/max）与典型值（typ）。typ 不是承诺，不能用于最坏情况设计。
4. 手册没写的写“未给出”，不要用经验值补。
5. 选型结论、外部知识、手册事实分开标注。

## 类型速查

### MCU / SoC / DSP

- **必抓**：内核与主频、Flash/RAM、外设数量（UART/SPI/I2C/ADC/定时器/PWM）、总线与高速接口、工作电压、温度范围、封装、启动时间、低功耗模式与唤醒时间。
- **选型**：外设和引脚是否够用；引脚复用是否冲突；生态、工具链、供货周期。
- **常见坑**：GPIO 数量被调试口/晶振占用；ADC 参考电压与输入范围；Flash 等待周期随主频变化；Errata 里的外设限制。

### 模拟 / 信号链（运放、比较器、仪表放大器、滤波器）

- **必抓**：增益带宽积、压摆率、输入失调电压/漂移、输入偏置电流、共模范围、输出摆幅、噪声密度、失真、电源电压、单位增益稳定性。
- **选型**：信号频率与增益是否在 GBW 内；压摆率是否够；单电源/双电源；轨到轨输入输出是否真实。
- **常见坑**：GBW 是大信号还是小信号；容性负载导致振荡；输入共模接近电源轨时性能下降；失调漂移随温度变化。

### 电源（LDO、DC-DC、PMIC、充电管理）

- **必抓**：输入/输出电压范围、输出电流、效率曲线、开关频率、纹波、静态电流、关断电流、压差、负载/线性调整率、软启动、保护（OVP/OCP/OTP）、外部元件要求。
- **选型**：最小输入与最大负载组合下的压差/效率；轻载效率；热耗散；是否需要外部电感/电容。
- **常见坑**：LDO 压差不够导致掉压；DC-DC 电感饱和电流不足；输出电容 ESR 超出稳定范围；热焊盘未接地；使能/上电时序。

### 传感器 / MEMS

- **必抓**：量程、分辨率、精度/误差、零点漂移、灵敏度、非线性、交叉轴灵敏度、采样率、输出接口（模拟/I2C/SPI）、供电、温度范围、封装。
- **选型**：精度和量程是否覆盖被测信号；响应时间；是否需要校准；机械安装方向。
- **常见坑**：精度写成“典型值”；温漂未计入；I2C 地址冲突；封装应力影响零点；采样率与滤波带宽不匹配。

### ADC / DAC

- **必抓**：分辨率、采样率、INL/DNL、SNR/SINAD、ENOB、输入范围、参考电压、接口、功耗、通道数。
- **选型**：有效位数是否满足精度；输入驱动/缓冲要求；参考源噪声；采样保持时间。
- **常见坑**：标称位数不等于有效位数；参考电压噪声限制精度；输入未加驱动导致建立不足；数字接口时序。

### 接口 / 收发器（CAN、RS-485、USB、Ethernet、HDMI 等）

- **必抓**：协议标准与速率、通道数、供电、逻辑电平、ESD/浪涌等级、隔离耐压、共模范围、终端电阻、封装。
- **选型**：协议兼容性；速率与线缆长度；隔离需求；节点数；失效保护。
- **常见坑**：ESD 等级是接触还是空气放电；总线终端缺失；共模范围不足；不同速率等级不能混用。

### 存储器（Flash、EEPROM、SRAM、DRAM）

- **必抓**：容量、接口、速度、页/扇区大小、擦写寿命、数据保持时间、工作电压、温度范围、封装。
- **选型**：寿命与写入频率；擦除粒度；启动方式（XIP/映射）；供货与停产状态。
- **常见坑**：擦写寿命按扇区计算；写入前必须擦除；高温下保持时间缩短；时序模式配置错误。

### 逻辑 / 电平转换

- **必抓**：电源电压、输入阈值、输出驱动、传播延迟、通道数、方向控制、上下拉要求、封装。
- **选型**：两侧电压范围；开漏/推挽；双向还是单向；速率。
- **常见坑**：输入阈值随 VCC 变化；开漏需要上拉；双向转换器的速率限制；未使用的输入不能悬空。

### MOSFET / IGBT / 功率开关

- **必抓**：VDS/VCE、ID、RDS(on)（及其测试条件）、栅极电荷 Qg、输入/输出电容、栅极阈值电压、雪崩能量、SOA、热阻、封装。
- **选型**：RDS(on) 对应的 VGS 和温度；Qg 与驱动能力；SOA 是否覆盖启动/短路；热设计。
- **常见坑**：RDS(on) 标称值通常在 25°C、特定 VGS 下；高温下 RDS(on) 显著上升；SOA 不覆盖线性区；栅极振荡。

### 二极管 / TVS / ESD / 齐纳

- **必抓**：反向电压、正向电流、正向压降、反向漏电、钳位电压、峰值脉冲功率、结电容、响应时间、封装。
- **选型**：钳位电压是否低于被保护器件耐压；结电容是否影响信号；脉冲波形定义。
- **常见坑**：TVS 钳位电压按特定波形定义；ESD 与浪涌不是同一等级；结电容影响高速信号；反向漏电随温度上升。

### 光电器件（LED、光耦、光电二极管）

- **必抓**：正向电流/压降、发光强度/波长、光耦的 CTR、隔离电压、传输速率、暗电流、响应时间、视角、封装。
- **选型**：CTR 随温度/寿命衰减；隔离等级；驱动电流；光耦速率。
- **常见坑**：CTR 是最小值还是典型值；LED 光衰；光耦需要限流和上拉；隔离电压是 RMS 还是峰值。

### 晶振 / 时钟

- **必抓**：频率、频率容差、负载电容、ESR、驱动电平、工作温度、老化率、封装、输出类型（晶体/振荡器）。
- **选型**：负载电容匹配；启动时间；相位噪声/抖动；温度频差。
- **常见坑**：晶体不是振荡器，需要匹配电路；负载电容算错导致频偏；ESR 过高导致不起振；PCB 寄生电容。

### 继电器 / 开关 / 连接器

- **必抓**：额定电压/电流、接触电阻、绝缘电阻、耐压、机械/电气寿命、触点形式、引脚间距、插拔次数、工作温度。
- **选型**：负载类型（阻性/感性/容性）；降额；插拔寿命；防呆与锁扣。
- **常见坑**：额定电流未按负载类型降额；感性负载需要续流；触点粘连；连接器端子与线径不匹配。

### 被动元件（电阻、电容、电感、磁珠）

- **必抓**：阻值/容值/感值、容差、额定功率/电压/电流、温度系数、ESR/ESL、自谐振频率、封装尺寸、寿命。
- **选型**：降额（电压/功率/温度）；高频特性；直流偏压下的容值变化；电感饱和电流。
- **常见坑**：MLCC 直流偏压导致容值大幅下降；电阻功率按 70°C 以上降额；电感饱和电流不是额定电流；磁珠的直流电阻。

### RF 模块 / 天线

- **必抓**：频段、调制方式、发射功率、接收灵敏度、接口、供电、天线形式、认证、工作温度、尺寸。
- **选型**：频段与法规认证；链路预算；天线净空；功耗。
- **常见坑**：模块认证不等于整机认证；天线净空不足；发射功率是典型值；灵敏度受带宽影响。

### 隔离 / 栅极驱动

- **必抓**：隔离耐压、共模瞬态抗扰度（CMTI）、传输速率、传播延迟、通道数、驱动电流、欠压锁定（UVLO）、死区时间。
- **选型**：隔离等级与安规距离；CMTI；驱动电流与 Qg；UVLO 阈值。
- **常见坑**：隔离电压是工作电压还是测试电压；CMTI 条件；驱动回路寄生电感；负压关断需求。

### 电池 / 保护 / 电量计

- **必抓**：化学体系、标称/充电/截止电压、容量、内阻、充放电倍率、循环寿命、保护阈值、温度范围。
- **选型**：容量与倍率；保护板参数；电量计算法；热管理。
- **常见坑**：容量随倍率和温度变化；保护板过流阈值；循环寿命定义；运输法规。

## 跨类型检查

### 参数表读法

- 先确认表头：Parameter、Conditions、Min、Typ、Max、Unit。
- 注意测试条件列：VCC、负载、温度、频率不同，数值不可直接比较。
- 注意脚注：注释 1/2/3 常包含关键限定条件。
- 注意“preliminary”“advanced information”：参数可能还会变。

### 生命周期与文档

- 查 Ordering Information：型号后缀决定封装、温度等级、包装。
- 查 Revision History：版本差异可能影响参数或勘误。
- 查 Errata / Product Change Notice：外设限制和已知问题。
- 查生命周期：Active / NRND / Obsolete / Last Time Buy。

### 热与布局

- 热阻、结温、环境温度、功耗共同决定是否需要散热。
- 热焊盘、过孔、铜箔面积是规格的一部分。
- 去耦电容要按手册要求的容值和位置布置。
- 高速/时钟/模拟走线需要地屏蔽和回流路径。

## 按用户问题裁剪

| 用户问题 | 重点呈现 |
|----------|----------|
| “能不能用在我的电路里” | 输入/输出范围、接口电平、功耗、温度、封装、外围元件 |
| “帮我选一个替代型号” | 引脚兼容、电气兼容、时序/封装差异、生命周期、供货 |
| “帮我做设计评审” | 绝对最大值裕量、推荐工作条件、外围元件、布局、上电时序、热 |
| “为什么板子会坏” | 绝对最大值、ESD/浪涌、热、时序、Errata、输入悬空 |
| “给我讲讲这个芯片” | 架构/框图、关键特性、典型应用、主要参数，不必展开全部脚注 |

> 某一维度确实没有重要结论时，写“无特别需要注意的点”，不要为了填模板编内容。
