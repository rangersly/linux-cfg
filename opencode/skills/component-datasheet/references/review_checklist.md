# 报告校验清单

在交付前逐项检查。任何一项不通过，先修正再输出。

## 数值与条件

- [ ] 每个关键数字都有单位。
- [ ] 每个关键数字都有测试条件（电压、负载、温度、频率等）。
- [ ] 每个关键数字都有页码或章节来源。
- [ ] 没有把典型值（typ）写成保证值。
- [ ] 没有把最大值（max）当成推荐值。
- [ ] 没有混用 min/typ/max 列。
- [ ] 绝对最大额定值与推荐工作条件分开呈现。
- [ ] 超出推荐工作条件但在绝对最大值内的用法，已明确说明“不保证工作”。
- [ ] 温度范围、降额曲线、热阻已纳入结论。
- [ ] 单位换算正确（mA/A、°C/K、ns/µs、mV/V）。

## 器件与文档

- [ ] 型号、厂商、文档版本已核对。
- [ ] 生命周期状态已确认（Active / NRND / Obsolete / Preliminary）。
- [ ] 多封装/多引脚变体的引脚映射差异已说明。
- [ ] 引脚图方向（顶视/底视）已注明。
- [ ] 引脚编号与名称来自引脚图或引脚表，不是猜测。
- [ ] 已查 Revision History 和 Errata。
- [ ] 手册内部的矛盾已标注两处页码，没有静默取舍。

## 设计与风险

- [ ] 外围元件（电容、电感、电阻、上拉/下拉）要求已列出。
- [ ] 去耦、热焊盘、地平面、走线要求已检查。
- [ ] 上电/关断时序、复位、使能、时钟要求已检查。
- [ ] ESD/浪涌/隔离/保护要求已检查。
- [ ] 未使用引脚、NC 引脚、 strapping/boot 引脚已检查。
- [ ] 常见坑与失效模式已列出。
- [ ] 选型替代信息标注了 `[外部知识]`，没有伪装成手册结论。

## 交付质量

- [ ] 用户最初的问题被直接回答。
- [ ] 报告结论先行，不是按页复述。
- [ ] 参数表可读，没有把整页文字塞进表格。
- [ ] 信息缺口已列出，没有编造数值。
- [ ] 对话摘要控制在 5-8 条，包含结论、关键参数、最重要警告。
- [ ] 页码使用 PDF 物理页码；与印刷页码不同时已注明。
